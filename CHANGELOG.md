# Changelog

Все важные изменения в этом проекте будут документированы в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/),
и этот проект придерживается [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.0.6] - 2026-08-21

### Исправлено
- **BuildManager**: переписана логика сборки курса — переход от Output Channel к VS Code Terminal для всех операций сборки. Ранее `buildCourse` использовал Output Channel без полной очистки кэша Vite и целевых директорий, что приводило к пропаданию иконок UnoCSS. Теперь обе функции сборки (`buildLecture` и `buildCourse`) используют единый terminal-based подход с гарантированной очисткой `node_modules/.vite`, `dist/` и выходных директорий перед каждой сборкой.
- **tsconfig.json**: добавлен `"vscode"` в `compilerOptions.types` для корректной компиляции с типами VS Code API.
- **package.json**: обновлён минимальный VS Code API до ^1.90.0.
- **commands.ts**: устранён лишний аргумент `outputChannel` в вызове `buildManager.buildCourse()`.

## [0.0.5] - 2026-08-20

### Исправлено
- **Constants и LectureManager**: удалены несуществующие npm-пакеты `@slidev/preset-monaco`, `@slidev/preset-katex`, `@slidev/preset-mermaid`, `@slidev/preset-drauu` из зависимостей модулей. Эти пакеты не существуют на npm — Monaco, KaTeX, Mermaid и Drauu встроены в Slidev из коробки. Установка зависимостей лекций с включёнными модулями теперь проходит успешно.

## [0.0.4] - 2026-08-20

### Исправлено
- **BuildManager**: добавлена очистка Vite-кэша (`node_modules/.vite`, `dist/`) перед каждой сборкой лекции — устранена проблема со stale-иконками UnoCSS
- **BuildManager**: добавлена очистка целевой директории перед копированием артефактов — устранено смешивание CSS/JS файлов от разных сборок

### Удалено
- **testIcons**: удалена debug-команда `sliman.testIcons` и связанные регистрации

## [0.0.3] - 2026-08-20

### Добавлено
- **Два режима сборки**: добавлен режим сборки лекций в корень курса (наряду с существующим режимом). Теперь поддерживаются оба режима.

### Изменено
- **BuildManager**: переписана логика деплоя — поддержка двух режимов сборки
- **CourseManager**: обновлён path resolution для поддержки нового режима
- **Commands**: рефакторинг команд, улучшена обработка ошибок
- **Тесты**: добавлены тесты для BuildManager и CourseManager

### Исправлено
- Фикс сборки лекций и курса

## [0.0.2] - 2026-02-04

### Добавлено
- **Модульная система лекций**
  - Возможность выбора дополнительных модулей при создании лекции
  - Интерактивный диалог выбора модулей
  - Автоматическая настройка package.json и конфигурационных файлов

- **Поддерживаемые модули:**
  - **Shiki** — красивая подсветка синтаксиса кода
  - **Monaco Editor** — интерактивный редактор кода (JavaScript, TypeScript, Python, Java, C++, C#, SQL и др.)
  - **KaTeX** — рендеринг математических формул LaTeX
  - **Mermaid** — создание диаграмм и блок-схем
  - **Drauu** — инструменты рисования и аннотаций на слайдах
  - **Iconify** — библиотека иконок (7000+ иконок из наборов MDI, Carbon и др.)

- **Тестовые лекции**
  - Готовые примеры для каждого модуля в template/
  - Monaco, Mermaid, KaTeX, Iconify, Drauu тестовые лекции

- **Документация**
  - `iconify-usage-guide.md` — полное руководство по использованию Iconify
  - `monaco-usage-guide.md` — полное руководство по Monaco Editor

### Изменено
- **LectureManager**: переработан для поддержки модульной системы
- **Constants**: добавлены ModuleInfo и AVAILABLE_MODULES для модулей
- **commands.ts**: добавлена команда выбора модулей selectModules

## [0.0.1] - 2026-02-02

### Добавлено
- **Управление курсами**
  - Создание новых курсов с готовой структурой
  - Сканирование и анализ существующих курсов
  - Чтение и запись конфигурации курса (sliman.json)

- **Управление лекциями**
  - Добавление новых лекций с автогенерацией имен папок
  - Создание структуры лекций (slides.md, package.json)
  - Установка зависимостей для лекций
  - Обновление конфигурации курса при добавлении лекций

- **Course Explorer**
  - Древовидный интерфейс для навигации по курсу в боковой панели VS Code
  - Отображение структуры курса: действия + список лекций
  - Автоматическое обновление при изменениях в файловой системе
  - Быстрый доступ к командам: View, Edit, Build, Delete для каждой лекции
  - Действия курса: Add Lecture, View Course

- **Сборка и публикация**
  - Сборка отдельных лекций в статические файлы
  - Пакетная сборка всего курса
  - Запуск dev сервера для разработки
  - Локальный HTTP сервер для просмотра курса
  - Настройка GitHub Pages для автоматического деплоя

- **Команды расширения**
  - `sliman.createCourse` → "Create Course" - Создание нового курса
  - `sliman.scanCourse` → "Scan Course" - Сканирование курса
  - `sliman.addLecture` → "Add Lecture" - Добавление новой лекции
  - `sliman.editLecture` → "Edit Lecture" - Редактирование лекции с dev сервером
  - `sliman.deleteLecture` → "Delete Lecture" - Удаление лекции
  - `sliman.buildLecture` → "Build Lecture" - Сборка лекции
  - `sliman.viewCourse` → "View Course" - Просмотр курса
  - `sliman.openSlides` → "Open slides.md" - Открытие файла слайдов
  - `courseExplorer.refresh` → "Refresh" - Обновление Course Explorer

- **Утилиты и вспомогательные функции**
  - Транслитерация кириллицы в латиницу для имен папок
  - Валидация имен курсов и лекций
  - Управление контейнером менеджеров (Singleton паттерн)
  - Обработка ошибок и прогресс-индикаторы

- **Шаблоны**
  - Готовые шаблоны для лекций (slides.md)
  - Шаблон главной страницы курса (index.html)
  - Шаблон package.json для лекций
  - GitHub Actions workflow для автоматического деплоя

- **Тестирование**
  - Модульные тесты для всех основных компонентов
  - Интеграционные тесты с использованием @vscode/test-electron
  - Тестовые утилиты для работы с временными директориями
  - Категорийные тесты для разных менеджеров

### Архитектура
- **Модульная структура**: Разделение ответственности между менеджерами
- **TypeScript**: Полная типизация с строгими настройками
